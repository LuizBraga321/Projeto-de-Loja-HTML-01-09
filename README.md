# LojaPromo

Projeto de uma loja virtual desenvolvido utilizando apenas HTML.

O objetivo do projeto é praticar a estruturação de páginas web, navegação entre arquivos, utilização de tabelas, formulários, imagens, links e outros elementos fundamentais do HTML.

## Sobre o projeto

A LojaPromo é uma loja virtual fictícia criada como projeto de estudo.

O site possui diferentes páginas que simulam partes de um e-commerce, como catálogo de produtos, favoritos, carrinho, formas de pagamento e informações sobre a loja.

## Páginas do site

O projeto possui as seguintes páginas:

- `Produtos1.html` — página principal com os produtos disponíveis.
- `Favoritos2.html` — produtos adicionados aos favoritos.
- `Carrinho3.html` — produtos adicionados ao carrinho.
- `pagamento4.html` — página com as formas de pagamento.
- `SobreaLoja5.html` — informações sobre a LojaPromo.

## Categorias de produtos

Na página principal, os produtos estão organizados em categorias como:

- Móveis
- Informática
- Limpeza
- Celulares

Cada produto possui informações como:

- Nome
- Imagem
- Descrição
- Preço promocional
- Preço anterior
- Opção de compra
- Opção de adicionar ao carrinho
- Opção de adicionar aos favoritos

## Formas de pagamento

A página de pagamento possui formulários separados para diferentes métodos:

- Cartão de crédito ou débito
- Boleto bancário
- Pix
- Transferência bancária

Os formulários utilizam elementos como:

- `<form>`
- `<label>`
- `<input>`
- `<button>`
- `<details>`
- `<summary>`

Também foram utilizados diferentes tipos de campos, como:

- `text`
- `email`
- `tel`
- `month`

## Tecnologias utilizadas

- HTML5

Neste momento, o projeto foi desenvolvido utilizando apenas HTML, sem CSS ou JavaScript.
